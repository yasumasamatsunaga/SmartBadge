# SmartBadge 実機検証記録（2026-10-20〜21）

## 対象と検証方法

- ドウシシャ SmartBadge EB180TSL 系（ユーザー実機）
- 任意の映像を切り出し、360×360pxの黒背景キャンバス内に配置
- アプリでの読み込み・プレビューと、SmartBadge本体での実再生を分けて確認
- 検証に用いた動画素材はリポジトリに含めない

## 実機で観測した結果

| ファイル種別 | 条件 | アプリ | 本体での観測 |
| --- | --- | --- | --- |
| GIF | 61秒・12fps | 61秒プレビュー | 約9秒に短縮されたように見えた |
| GIF | 9秒・10〜12fps | 読み込み成功 | 動くがカクつく |
| GIF | 4秒・15/18/24fps | 読み込み成功 | ほぼ静止した |
| MP4 | 初期のエンコード設定・61秒 | 読み込みできず | 未確認 |
| MP4 | 4秒・24fps・H.264 Baseline | 読み込み成功 | **非常に滑らか** |
| MP4 | 9秒・24fps・SEC 00〜08カウンター付き | 読み込み成功 | **SEC 08まで進行** |
| MP4 | 9秒・24fps・元動画から直接変換 | 読み込み成功 | **連続した動きを滑らかに再生、ユーザーが成功を確認** |

**重要:** 9秒は「再生に成功した時間」であり、最大再生時間を意味しません。GIFのフレーム間隔、内部形式、デコード処理のどれが本体の挙動に影響したかは未確定です。

## 推奨エンコード条件（実機検証済み v1.0）

- 360×360px、24fps、`yuv420p`
- MP4 / H.264 Constrained Baseline / level 3.0
- `-an -crf 20 -g 48 -bf 0 -movflags +faststart`
- 9秒は216フレームに固定
- 元素材の表示したい範囲は個別にcropして中央配置

### 汎用コマンド例

```bash
# 被写体を切らない安全領域270×270pxへのフィット
bash scripts/convert.sh input.mp4 output.mp4 0 9 none 270 270

# 被写体を切り出して表示を大きくする例（座標は説明用）
bash scripts/convert.sh input.mp4 cropped.mp4 0 9 400:500:100:50 224 280
```

この例のcrop値は検証に使用した元映像の座標ではありません。必要な範囲は素材ごとに決めてください。再生時間の限界は別途検証が必要です。動画本体や第三者の著作物は公開しません。
