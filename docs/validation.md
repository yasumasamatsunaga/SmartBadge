# SmartBadge 実機検証記録（2026-10-20〜21）

## 対象

- ドウシシャ SmartBadge EB180TSL 系（ユーザー実機）
- 黒背景のゲーム画面から中央の迷路だけを切り出し、360×360pxキャンバスに配置
- 動画素材は公開リポジトリに含めない

## 実機で観測した結果

| ファイル種別 | 条件 | アプリ | 本体での観測 |
| --- | --- | --- | --- |
| GIF | 61秒・12fps | 61秒プレビュー | 約9秒に短縮されたように見える |
| GIF | 9秒・10〜12fps | 読み込み成功 | 動くがカクつく |
| GIF | 4秒・15/18/24fps | 読み込み成功 | ほぼ静止した |
| MP4 | 以前の設定・61秒 | 読み込みできず | 未確認 |
| MP4 | 4秒・24fps・H.264 Baseline | 読み込み成功 | **非常に滑らか** |
| MP4 | 9秒・24fps・SEC 00〜08表示 | 読み込み成功 | **SEC 08まで進行** |
| MP4 | 9秒・24fps・元ゲーム映像から直接変換 | 読み込み成功 | **滑らかに再生・ユーザーが完成を確認** |

GIFフレーム間隔や本体のデコード制限などについての仮説は未確定です。MP4の9秒再生成功は確認できましたが、**9秒が最大再生時間とは検証していません**。

## 成功時の変換例

```bash
ffmpeg -hide_banner -loglevel error -y \
  -ss 52 -i source.mkv -an \
  -vf 'crop=550:624:365:57,scale=232:264:flags=lanczos,pad=360:360:64:48:black,fps=24,format=yuv420p' \
  -frames:v 216 -c:v libx264 -profile:v baseline -level:v 3.0 \
  -pix_fmt yuv420p -crf 20 -g 48 -bf 0 \
  -movflags +faststart output.mp4
```

このcrop座標は特定の元映像にのみ対応します。YouTube素材の出所を示す際にも、利用許諾がない複製ファイルをリポジトリへ含めないでください。
